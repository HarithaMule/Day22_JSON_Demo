This project demonstrates how to read JSON data in JavaScript and display it on a web page using basic DOM manipulation.
It is a simple beginner-level example to understand JSON objects, arrays, and dynamic HTML rendering.

**Features**
Uses JSON array of objects
Displays student details on the web page
Demonstrates DOM manipulation
Beginner-friendly and easy to understand
No external libraries required

**Code Explanation**
Student data is stored in a JSON-like array
JavaScript loops through the data using forEach()
Student details are dynamically added to the webpage using innerHTML
